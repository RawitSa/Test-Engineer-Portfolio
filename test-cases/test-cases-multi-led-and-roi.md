# Test Cases — โหมด multi_led, การวาด ROI, การตามชิ้นงาน และ AI

ที่มา: ออกแบบจากพฤติกรรมที่กำหนดของระบบ
สถานะ "Run (จำลอง)" = รันด้วยโค้ดจำลองในสภาพแวดล้อมทดสอบ ไม่ใช่ hardware จริง · "Not run" = ยังไม่ได้รันบนเครื่องจริง

## B. วาด ROI

| ID | หัวข้อ | Steps | Expected |
|----|--------|-------|----------|
| TC-ROI-01 | วาดขณะตามจออยู่ | วาด ROI ใหม่ภายในภาพ | ตำแหน่งตรงกับที่ลาก สถานะ `shift / zoom compensated` |
| TC-ROI-02 | กรอบเลยขอบภาพ | ลากกรอบให้เลยขอบล่าง | ตัดให้อยู่ในภาพ สถานะ `box touched the picture edge` ตำแหน่งไม่เยื้อง |
| TC-ROI-03 | วาดขณะไม่ได้ตามจอ | วาดตอนสถานะ `searching for the LCD (0/21)` | ขึ้นคำเตือน ถ้าไม่บันทึก → `ROI not saved (LCD not tracked)` |
| TC-ROI-04 | ขนาดที่บันทึกสอดคล้องกัน | เทียบขนาด `1Image1.png` กับ `1RectangleWidth/Height.txt` | ขนาดรูป + 2×pad เท่ากับค่าในไฟล์ |

## C. การตามชิ้นงาน / ซูม (regression)

| ID | หัวข้อ | Steps | Expected |
|----|--------|-------|----------|
| TC-ROI-05 | เปลี่ยนซูมเล็กน้อย | ปรับ zoom ที่เลนส์เล็กน้อย | log `LCD found at zoom xN` กรอบตามกลับมา |
