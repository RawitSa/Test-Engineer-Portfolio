# BUG-003 — หมุนชิ้นงานแล้ว symbol ไม่ถูกจับต่อเนื่องเหมือนเดิม (Regression)

| หัวข้อ | รายละเอียด |
|--------|-------------|
| Severity | High (regression ของความสามารถเดิม ทำให้ตีตกของดี) |
| Component | ระบบตามชิ้นงาน (tracker) หลังเพิ่มระบบตามซูม |
| Environment | เครื่องทดสอบจริง ขณะหมุนชิ้นงาน (log แสดง `turned 2 deg`) |
| ผู้รายงาน | [ชื่อคุณ] |

## Steps to reproduce
1. ให้ระบบตามชิ้นงานอยู่ในสถานะปกติ
2. หมุนชิ้นงานเหมือนที่เคยทำกับเวอร์ชันก่อนเพิ่มระบบตามซูม

## Expected
symbol ถูกจับต่อเนื่องเหมือนเวอร์ชันก่อนหน้า

## Actual
symbol หลุดบ่อยขึ้นระหว่างหมุน

## Analysis (จากการอ่านโค้ด ยังไม่ได้ยืนยันด้วยการวัด)
1. ตอนค้นหา LCD ทั้งภาพ ระบบวนลองซูม 15 ค่า ซูมปกติถูกลองแค่ 1 ใน 15 ครั้ง จึงจับกลับช้ามาก
2. ระหว่างหมุน symbol ที่ตรงกันน้อยและคลาด ค่าซูมที่ประมาณได้แกว่ง กล่องสั่นแล้วหลุด
- สาเหตุราก: ฟีเจอร์ใหม่ (ตามซูม) กระทบเส้นทางเดิม (หาตำแหน่งตอนหมุน) ที่ไม่ได้ regression test

## Fix และสถานะ
- ค้นหาที่ซูมปกติทุกครั้งเต็มความเร็ว ลองซูมอื่นเฉพาะเมื่อหา LCD ไม่เจอต่อเนื่องเกิน ~2 วินาที
- ตามซูมละเอียดเฉพาะเมื่อมี symbol ตรงกัน ≥ 8 ตัวที่อยู่ห่างกัน และซูมเบี่ยงไม่เกิน 8%
- ผลข้างเคียงที่ยอมรับ: หลังเปลี่ยนเลนส์ การหาซูมใหม่ใช้เวลาราว 10 วินาที
- สถานะ: **แก้ในโค้ดแล้ว รอผลทดสอบซ้ำบนเครื่องจริง** `[อัปเดตเมื่อทดสอบแล้ว]`
- ข้อเสนอ: เพิ่มสวิตช์ปิดระบบตามซูมเมื่อล็อกเลนส์แล้ว

## Regression test ที่ควรมีหลังจากนี้
เพิ่มเคสหมุนชิ้นงานหลายความเร็ว/มุม ลงใน test suite ทุกครั้งที่แก้ระบบตามชิ้นงาน (ดู TC-ROI-06)
